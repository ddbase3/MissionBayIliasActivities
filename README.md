
## Namespace migration on ILIAS 11

This module is installed at `components/Base3/MissionBayIliasActivities/` under the ILIAS project root. Its PHP namespace is `Base3\MissionBayIliasActivities`, and the `base3.json` dependencies name `CoreFoundation`, `Base3Ilias`, `AssistantFoundation`, and `MissionBay`. Native `ILIAS\...` namespaces remain owned by ILIAS. See [privacy and data processing](PRIVACY.md).
